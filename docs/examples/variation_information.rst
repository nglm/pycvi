Using the Variation of Information
------------------------------------

In this example, we compute the variation of information between the true
clustering and a clustering predicted with the true number of clusters,
:math:`k`. Here, :math:`k` is the main parameter of ``KMeans`` and is set to
the known number of clusters in the dataset. A high variation of information
(VI) indicates that clustering generated by the clustering method does not represent data well. A high VI value between the true clustering and a generated clustering assuming the correct number of clusters is often due to the clustering method not being suitable for the data, or due to the hyperparameter values of the clustering method not being suitable for this data.
